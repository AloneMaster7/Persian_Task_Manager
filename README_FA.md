# Persian Win32 Task Manager

یک برنامهٔ سبک و بومی ویندوز برای مدیریت و اولویت‌بندی کارها؛ نوشته‌شده با C++ و Win32 API، بدون نیاز به Qt یا فریم‌ورک‌های سنگین.

## امکانات

- دسته‌بندی کارها در پنج گروه الف تا هـ و مرتب‌سازی خودکار بر اساس اولویت
- افزودن، ویرایش و حذف کارها
- ویرایش عنوان و دسته‌بندی با دوبار کلیک روی ردیف
- انتخاب چند کار با نگه‌داشتن `Ctrl` و حذف گروهی با دکمهٔ حذف یا کلید `Delete`
- ذخیره و بازیابی اطلاعات در فایل `tasks.dat` کنار فایل اجرایی
- تنظیم اجرای خودکار هنگام ورود به ویندوز
- رابط کاربری فارسی و راست‌به‌چپ برای متن‌ها، بدون آینه‌ای شدن چیدمان کنترل‌ها
- نمایش آیکون اختصاصی برنامه در پنجره، فایل اجرایی و ناحیهٔ اعلان ویندوز (System Tray)
- کوچک‌شدن پنجره به System Tray با دکمهٔ کمینه‌سازی یا بستن پنجره؛ کلیک روی آیکون برنامه را برمی‌گرداند
- منوی آیکون کنار ساعت برای بازکردن برنامه، دیدن پنجرهٔ «درباره برنامه» یا خروج کامل
- پنجرهٔ «درباره برنامه» با پیوندهای قابل کلیک به GitHub و کانال تلگرام

## افزودن آیکون اختصاصی

فقط یک فایل آیکون ویندوز با نام دقیق `icon.ico` در کنار `TaskManager.cpp` و فایل‌های ساخت قرار دهید:

```text
Project/
├── TaskManager.cpp
├── icon.ico              <-- آیکون خودتان را اینجا قرار دهید
├── build.bat
├── build.sh
├── README.md
└── README_FA.md
```

نیازی نیست فایل `.rc` را دستی بسازید. اسکریپت‌های `build.bat` و `build.sh` هنگام کامپایل یک فایل `.rc` موقت تولید می‌کنند، آن را با `windres` به منبع قابل لینک تبدیل می‌کنند و در پایان فایل‌های موقت را پاک می‌کنند. آیکون در فایل اجرایی قرار می‌گیرد؛ بنابراین پس از ساخت، برای نمایش آیکون پنجره، فایل EXE و System Tray لازم نیست `icon.ico` کنار EXE باشد.

ترجیحاً فایل ICO چند اندازهٔ استاندارد مثل 16×16، 32×32، 48×48 و 256×256 داشته باشد. تغییر نام PNG به ICO کافی نیست؛ فایل باید واقعاً در قالب ICO باشد.

## ساخت برنامه در ویندوز

پروژه برای MSYS2 UCRT64، GCC و C++11 آماده شده است. بسته‌های ابزار GCC و binutils (شامل `windres`) باید نصب باشند.

**روش اول:** فایل `build.bat` را اجرا کنید. این اسکریپت از مسیر زیر استفاده می‌کند:

```text
C:\msys64\ucrt64\bin
```

**روش دوم:** ترمینال MSYS2 UCRT64 را باز کنید، وارد پوشهٔ پروژه شوید و اجرا کنید:

```bash
bash build.sh
```

فایل خروجی `TaskManager.exe` در همان پوشه ساخته می‌شود.

## رفتار System Tray

- با کمینه‌کردن یا زدن دکمهٔ بستن پنجره، برنامه به‌طور کامل خارج نمی‌شود و در ناحیهٔ اعلان کنار ساعت باقی می‌ماند.
- با کلیک روی آیکون، پنجرهٔ اصلی دوباره نمایش داده می‌شود.
- با راست‌کلیک روی آیکون، منوی بازکردن برنامه، دربارهٔ برنامه و خروج کامل نمایش داده می‌شود.
- برای بستن واقعی برنامه، گزینهٔ «خروج کامل» را از منوی آیکون انتخاب کنید. در صورت وجود تغییرات ذخیره‌نشده، برنامه دربارهٔ ذخیره‌کردن آن‌ها سؤال می‌کند.
