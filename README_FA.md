# برنامه مدیریت کارها برای ویندوز

یک برنامه دسکتاپ سبک برای ثبت و اولویت‌بندی کارها در پنج دسته. برنامه با **++C استاندارد C++11 و Win32 API بومی ویندوز** نوشته شده و رابط کاربری فارسی دارد.

- سیستم‌عامل: ویندوز ۱۰ به بالا (نسخه ۶۴ بیتی پیشنهاد می‌شود)
- رابط گرافیکی: Win32 API؛ بدون Qt، MFC یا فریم‌ورک گرافیکی جانبی
- کامپایلر پیشنهادی: GCC محیط MSYS2 UCRT64
- مجوز انتشار: MIT

## امکانات

- افزودن کار و اختصاص آن به یکی از پنج دسته.
- حذف کار انتخاب‌شده؛ حذف پس از ذخیره در فایل ثبت می‌شود.
- ذخیره اطلاعات در فایل `tasks.dat` کنار فایل اجرایی.
- حفظ کارهای ذخیره‌شده پس از بستن و اجرای مجدد برنامه.
- هنگام خروج با وجود تغییرات ذخیره‌نشده، امکان ذخیره، خروج بدون ذخیره یا لغو خروج نمایش داده می‌شود.
- ظاهر ساده با ترکیب رنگ آبی و سبز.
- نوشته‌های فارسی راست‌به‌چپ هستند، اما چیدمان و موقعیت کنترل‌ها آینه‌ای نشده است.

## معنی دسته‌ها

| دسته | تعریف |
|---|---|
| الف (A) | در صورت انجام ندادن، پیامدهای شدیدی دارد. |
| ب (B) | انجام آن سودمند است، اما انجام ندادنش پیامد شدیدی ندارد. |
| ج (C) | در صورت انجام ندادن، پیامدها جزئی هستند. |
| د (D) | کم‌اهمیت است و ممکن است انجام آن توسط فرد دیگری کارآمدتر باشد. |
| هـ (E) | ضرورت یا اهمیت خاصی ندارد. |

## پیش‌نیازها

1. ویندوز ۱۰ یا جدیدتر.
2. نصب [MSYS2](https://www.msys2.org/).
3. نصب GCC در محیط **MSYS2 UCRT64**.

اسکریپت `build.bat` مسیر پیش‌فرض `C:\msys64\ucrt64\bin\g++.exe` را استفاده می‌کند. اگر MSYS2 در مسیر دیگری نصب شده، مقدار `MSYS2_ROOT` را در فایل `build.bat` تغییر دهید.

## ساخت برنامه با MSYS2

### روش پیشنهادی: ترمینال UCRT64

1. مخزن را دانلود و از حالت فشرده خارج کنید یا با Git کلون کنید.
2. ترمینال **MSYS2 UCRT64** را باز کنید.
3. وارد پوشه پروژه شوید. نمونه:

   ```bash
   cd /c/path/to/Persian-Win32-Task-Manager
   ```

4. دستور زیر را اجرا کنید:

   ```bash
   bash build.sh
   ```

پس از ساخت موفق، فایل `TaskManager.exe` در همان پوشه ایجاد می‌شود.

### روش جایگزین: فایل Batch

می‌توانید `build.bat` را در ویندوز اجرا کنید. همچنین از داخل ترمینال UCRT64 امکان اجرای آن با دستور زیر وجود دارد:

```bash
cmd.exe /c build.bat
```

هر دو اسکریپت، فایل `TaskManager.cpp` را با استاندارد C++11 کامپایل کرده و کتابخانه کنترل‌های رایج ویندوز (`comctl32`) را لینک می‌کنند.

## ذخیره‌سازی اطلاعات

- اطلاعات کارها در فایل `tasks.dat` و در کنار `TaskManager.exe` ذخیره می‌شود.
- این فایل هنگام اولین ذخیره‌سازی ساخته می‌شود.
- برای انتقال کارها به پوشه یا رایانه دیگر، برنامه را ببندید و فایل `tasks.dat` را همراه فایل اجرایی منتقل کنید.
- اطلاعات کارها توسط برنامه به سرور ارسال نمی‌شود و به‌صورت محلی نگهداری می‌شود.
- فایل‌های اجرایی و `tasks.dat` در `.gitignore` قرار دارند تا تصادفاً وارد مخزن Git نشوند.
