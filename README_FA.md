# Persian Win32 Task Manager

یک برنامهٔ سبک و بومی ویندوز برای مدیریت و اولویت‌بندی کارها؛ نوشته‌شده با C++ و Win32 API، بدون نیاز به Qt یا فریم‌ورک‌های سنگین.

## امکانات

- دسته‌بندی کارها در پنج گروه الف تا هـ (از بالاترین تا پایین‌ترین اولویت)
- افزودن، ویرایش و حذف کارها
- **ویرایش کار با دوبار کلیک روی ردیف آن**؛ عنوان و دسته‌بندی در یک پنجرهٔ جداگانه قابل تغییر هستند
- **انتخاب چند کار با نگه‌داشتن Ctrl و کلیک روی ردیف‌ها** و حذف همهٔ موارد انتخاب‌شده با یک تأیید
- حذف گروهی با دکمهٔ حذف یا کلید Delete
- ذخیره و بازیابی اطلاعات در فایل `tasks.dat` کنار فایل اجرایی
- مرتب‌سازی خودکار کارها بر اساس اولویت
- گزینهٔ اجرای خودکار هنگام ورود به ویندوز از پنجرهٔ تنظیمات
- رابط کاربری فارسی و راست‌به‌چپ برای متن‌ها، بدون آینه‌ای شدن چیدمان کنترل‌ها

## دسته‌بندی‌ها

| گروه | تعریف |
|---|---|
| الف | در صورت انجام ندادن، پیامد شدید |
| ب | انجام آن سودمند است؛ بدون پیامد شدید در صورت انجام ندادن |
| ج | در صورت انجام ندادن، پیامد جزئی |
| د | کم‌اهمیت و مناسب واگذاری به دیگران |
| هـ | بدون ضرورت یا اهمیت |

## ساخت برنامه در ویندوز

این پروژه برای MSYS2 UCRT64 و GCC با استاندارد C++11 آماده شده است.

**روش اول:** در ویندوز فایل `build.bat` را اجرا کنید. این فایل کامپایلر را از مسیر زیر فراخوانی می‌کند:

```text
C:\msys64\ucrt64\bin\g++.exe
```

**روش دوم:** ترمینال MSYS2 UCRT64 را باز کنید، به پوشهٔ پروژه بروید و اجرا کنید:

```bash
bash build.sh
```

فایل خروجی `TaskManager.exe` در همان پوشه ساخته می‌شود.

## ذخیره‌سازی و سازگاری داده‌ها

اطلاعات در فایل `tasks.dat` کنار فایل اجرایی ذخیره می‌شوند. برای نگه‌داشتن کارهای قبلی، هنگام جایگزینی نسخهٔ برنامه فایل `tasks.dat` را نیز کنار فایل اجرایی جدید قرار دهید. ساختار ذخیره‌سازی این نسخه تغییر نکرده است.
