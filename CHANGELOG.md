# Changelog

## v1.3.0

- Added support for an embedded custom `icon.ico` application icon without requiring users to author an `.rc` file manually.
- Added a notification-area (System Tray) icon with restore, About, and full-exit actions.
- Closing or minimizing the main window now hides it to the System Tray; full exit remains available from the tray menu.
- Added a custom About window with clickable GitHub and Telegram links.
- Added a question-mark button beside Settings to open the About window.
- Preserved the existing task editing, multi-selection, priority sorting, startup setting, and `tasks.dat` format.
