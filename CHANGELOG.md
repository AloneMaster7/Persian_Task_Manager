# Changelog

## v1.2.2

- Added a dedicated edit window opened by double-clicking a task row.
- Added editing for task titles and categories; edited tasks are automatically re-sorted by priority.
- Replaced the settings button's hand-drawn gear with a cleaner three-slider settings icon.
- Enabled Ctrl-based multi-selection in the task list.
- Added multi-item deletion with a count-aware confirmation prompt; rows are removed from highest index to lowest to avoid index shifts.
- Kept the existing `tasks.dat` persistence format unchanged.
